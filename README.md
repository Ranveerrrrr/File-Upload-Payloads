## Overview

**File-Upload-Payloads** is a curated list of common file upload security payloads used for testing file upload vulnerabilities in web applications.  
This resource is intended for **bug bounty hunters**, **security testers**, and **developers** who want to harden their upload handling logic.

> These payloads are meant for **ethical testing only** on systems where you have explicit permission.

---

## How to Use

You can use the contents of this repository as:

1. A reference list while pentesting
2. A cheat sheet during bug bounty hunts
3. As test cases for your own upload filters
